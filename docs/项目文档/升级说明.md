## 一、怎么启动（每次学习前）

1. 双击 `mvp` 文件夹里的 **`start.bat`**
   - 它会自动用更准的检索模式（「真实模型编码」）启动
   - 如果 3000 端口被占用，它会问你要不要结束那个进程，按 `Y` 回车
2. 浏览器访问 **http://127.0.0.1:3000**
   - ⚠️ 不要双击 `public/index.html`，那样接口调不通
3. **学习期间别关那个黑窗口**，关了服务就停；想停就按 `Ctrl+C`

## 三、联网搜索怎么配（配一次就行）

1. 打开 http://open.bochaai.com ，微信扫码注册
2. 到「资源包」领 **免费试用 1000 次**
3. 回首页找「兑换」入口，输口令 `博查搜索`，**再送 1000 次**（共 2000 次）
4. 到「API KEY 管理」创建密钥，`sk-` 开头，**只显示一次，先存下来**
5. 回工作台，右上角 **⚙ 设置** → 把密钥粘进去 → 保存

配好之后就不用再管它了，它会**自己判断**什么时候该联网：

| 设置里的选项 | 行为 |
|---|---|
| **自动判断**（默认，推荐） | 先看本地知识库够不够；问题涉及时效信息（价格、版本、最新动态、"支持吗"）或本地答不好时，自动上网补 |
| 每次都联网 | 问什么都先搜一遍再答 |
| 从不联网 | 只用本地知识库回答 |

判断线是「本地匹配度 < 0.34 就去搜」。**你的知识库越用越厚，它就越不会乱联网。** 每次它做决定时都会把理由显示出来，不会偷偷干。
