商业需求文档。偏高层，讲为什么做这个产品、市场机会、商业模式、盈利预期，给老板和投资人看。

## 🟡 HTML / HyperText Markup Language

- **分类**：产品基础能力 → 技术基础概念
- **掌握程度**：理解
- **内容类型**：概念术语
- **痛点归属**：技术扫盲
- **解答的问题**：HTML是什么意思？

超文本标记语言，构建网页结构的语言，不是编程语言。所有网页底层都是HTML写的，浏览器把HTML代码渲染成可视化页面。HTML管结构，CSS管样式，JavaScript管交互。

## ⚪ 命令行 / Bash / Bash / Shell

- **分类**：产品基础能力 → 技术基础概念
- **掌握程度**：了解
- **内容类型**：概念术语
- **痛点归属**：技术扫盲
- **解答的问题**：命令行 / Bash是什么？产品经理需要掌握吗？

Bash是一种命令行解释器，就是程序员在黑色终端窗口里输入命令的环境。Linux和Mac默认自带。程序员用命令行运行代码、安装工具、操作文件、部署项目。产品经理不需要会写命令，知道'终端/命令行'是程序员敲命令干活的地方就行。

- **关联概念**：后端、部署、批处理文件

## ⚪ 批处理文件 .bat/.sh / Batch / Shell Script

- **分类**：产品基础能力 → 技术基础概念
- **掌握程度**：了解
- **内容类型**：概念术语
- **痛点归属**：技术扫盲

.bat是Windows的批处理文件，.sh是Mac/Linux的脚本文件。里面写了一串命令，双击或运行就能自动依次执行。程序员常用它做自动化操作，如一键部署、一键备份。

- **关联概念**：命令行/Bash、部署

- **分类**：产品基础能力 → 技术基础概念
- **掌握程度**：理解
- **内容类型**：概念术语

## 🟡 HTTP / HyperText Transfer Protocol

- **分类**：产品基础能力 → 技术基础概念
- **掌握程度**：理解
- **内容类型**：概念术语
- **痛点归属**：技术扫盲
- **解答的问题**：HTTP是什么意思？

超文本传输协议，浏览器和服务器之间通信的'交通规则'。打开网页、调用API底层都是HTTP在传数据。常见请求：GET（获取数据）、POST（提交数据）。常见状态码：200成功、404找不到、500服务器错误、401没权限。

- **关联概念**：API、后端、前端

## ⚪ 全盘加密（FDE） / Full-Disk Encryption

- **分类**：产品基础能力 → 技术基础概念
- **掌握程度**：了解
- **内容类型**：概念术语
- **痛点归属**：技术扫盲
- **解答的问题**：全盘加密是什么？产品经理需要掌握吗？

一种安全技术，把整个硬盘的数据全部加密，没有密码即使拿到电脑也读不到数据。Mac的FileVault、Windows的BitLocker都是FDE。做ToB企业产品、涉及敏感数据时客户经常会问。（注意：知识树里另有一个同名缩写 FDE 指「特性驱动开发」，两者无关，别混。）

- **关联概念**：后端、数据库、ToB

- **分类**：AI专属技术知识 → 大模型基础
- **掌握程度**：核心基础
- **内容类型**：概念术语
- **痛点归属**：通用认知
